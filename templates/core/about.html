Origine du projet

{{ APP_NAME }} est une application d'aide à la recherche documentaire sur le Japon : recherche dans les catalogues des institutions, bibliothèque personnelle et dossiers, traduction, exports.

Elle s'appelait auparavant Japon — Explorateur documentaire. Elle a été conçue d'après un cahier des charges du 12 novembre 2026, puis enrichie par les versions 1.2.0 et 1.3.0. La version 2.0.0 est une version de consolidation : fiabilité, tâches automatisées, documentation intégrée, et le nom {{ APP_NAME }}.

Les noms techniques n'ont pas changé, pour préserver les données existantes : projet Docker japon-explorateur-…, images, volumes et dépôt japon-explorateur.
