Avant de commencer

Installer J-ed sur un ordinateur Windows, pas à pas, sans rien connaître à Docker ni à PowerShell. Comptez une heure la première fois, surtout du temps d'attente. Chaque étape dit ce que vous devez voir.

L'assistant J-ed (le fichier J-ed.cmd) fait l'installation pour vous et vérifie lui-même chacun des points ci-dessous : s'il manque quelque chose, il l'affiche en rouge avec un bouton « Comment faire ? » qui mène à la bonne partie de cette page.

1. Ce qu'il faut

  • Windows 10 ou 11, en 64 bits, à jour. Docker Desktop demande au moins Windows 10 version 22H2 ou Windows 11 version 23H2 : ouvrez Paramètres → Windows Update et installez les mises à jour proposées.
  • 8 Go de mémoire conseillés (4 Go au minimum ; J-ed sera alors lent).
  • 20 Go de place libre sur le disque (voir plus bas).
  • Un compte administrateur de l'ordinateur, une seule fois, pour installer WSL et Docker Desktop.
  • Internet pendant l'installation. Ensuite, J-ed fonctionne aussi hors ligne (sauf la recherche dans les catalogues en ligne).

2. La virtualisation

Docker a besoin de la « virtualisation » du processeur. Pour savoir si elle est active :

  1. clic droit sur la barre des tâches, puis Gestionnaire des tâches ;
  2. onglet Performances, puis Processeur (ou « CPU ») ;
  3. en bas à droite, la ligne Virtualisation.

Attendu : « Virtualisation : Activé ».

Si vous lisez « Désactivé », elle s'active dans les réglages de démarrage de l'ordinateur (le BIOS ou l'UEFI), sous un nom comme Intel VT-x, Intel Virtualization Technology, AMD-V ou SVM. La façon d'y entrer change d'un fabricant à l'autre (souvent une touche comme F2, F10 ou Suppr au démarrage) : demandez de l'aide si vous n'êtes pas à l'aise. Sur une machine virtuelle, c'est un réglage de l'hôte (par exemple le type de processeur « host » sous Proxmox).

3. WSL

WSL est un composant de Windows dont Docker Desktop se sert. Pour l'installer :

  1. clic droit sur le bouton Démarrer, puis Terminal (administrateur) ; acceptez la question « Voulez-vous autoriser… » ;
  2. tapez la commande ci-dessous, puis Entrée :
wsl --install

Attendu : l'installation se déroule, puis Windows demande de redémarrer. Redémarrez.

Pour vérifier ensuite (dans un Terminal ordinaire) :

wsl --version

Attendu : une ligne « Version WSL : 2.x.x ». Si la commande n'est pas reconnue, ou si la version est plus ancienne que 2.1.5, tapez wsl --update.

4. Docker Desktop

Docker Desktop fait tourner J-ed dans des « conteneurs ». Il est gratuit pour un usage personnel, l'enseignement, les projets libres non commerciaux et les petites entreprises (moins de 250 salariés et moins de 10 millions de dollars de chiffre d'affaires) ; au-delà, Docker demande un abonnement payant.

  1. Téléchargez Docker Desktop pour Windows sur le site officiel : docker.com/products/docker-desktop (bouton de l'assistant : « Télécharger Docker Desktop »).
  2. Ouvrez le fichier téléchargé (Docker Desktop Installer.exe).
  3. Gardez l'option « Use WSL 2 » cochée, puis OK. L'installation dure quelques minutes.
  4. À la fin, cliquez sur Close (ou redémarrez si c'est demandé).

5. Démarrer Docker Desktop

  1. Ouvrez Docker Desktop depuis le menu Démarrer.
  2. La première fois : acceptez les conditions d'utilisation (Accept). La connexion à un compte Docker n'est pas nécessaire : vous pouvez passer cette étape (Skip).
  3. Attendez que la baleine de Docker, près de l'horloge, soit immobile, et que Docker Desktop affiche « Engine running » en bas à gauche.
Pour que J-ed soit prêt à chaque démarrage de l'ordinateur : dans Docker Desktop, Settings → General, cochez « Start Docker Desktop when you sign in to your computer ». J-ed redémarre ensuite tout seul avec Docker.

6. Place sur le disque

Docker et J-ed occupent environ 10 Go ; prévoyez 20 Go libres (plus si vous installez l'IA locale). Pour voir la place libre : ouvrez l'Explorateur de fichiers, puis Ce PC.

7. Télécharger J-ed

  1. Ouvrez la page des versions de J-ed : github.com/adupuisauteur/japon-explorateur/releases/latest.
  2. En bas, dans Assets, téléchargez les deux fichiers : japon-explorateur-X.Y.Z.zip et japon-explorateur-X.Y.Z.zip.sha256 (l'empreinte, qui permet de vérifier que l'archive est complète et intacte).
  3. Débloquez l'archive : clic droit sur le fichier .zip, Propriétés, cochez Débloquer en bas, puis OK (si la case n'existe pas, rien à faire).
  4. Clic droit sur le .zip, Extraire tout…, choisissez par exemple C:\J-ed, puis Extraire.

8. Ouvrir l'assistant

  1. Dans le dossier extrait, double-cliquez sur J-ed.cmd.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis Exécuter quand même (J-ed n'a pas de signature payante ; son code est public).

Attendu : la fenêtre « Assistant J-ed » s'ouvre au bout de quelques secondes. Elle vérifie les points 1 à 6 : « Prérequis : tout est prêt » en vert, sinon la liste de ce qui reste à régler.

9. Installer J-ed

  1. Cliquez sur Nouvelle installation.
  2. Archive : Choisir… et prenez le même fichier .zip (l'empreinte est trouvée toute seule), ou bien Télécharger la dernière version (GitHub).
  3. Gardez le nom, le port, l'emplacement et le dossier des sauvegardes proposés (ou changez-les), puis cliquez sur Installer.
  4. Attendez : la première installation prend 10 à 30 minutes (téléchargements). La fenêtre montre chaque étape ; elle se termine en vert.
  5. Cliquez sur 1. Créer le compte administrateur : J-ed s'ouvre dans le navigateur ; choisissez un identifiant et un mot de passe (10 caractères au moins).
  6. Si vous voulez : Créer les raccourcis (Bureau et menu Démarrer) et Charger le jeu d'essai (des notices fictives pour découvrir J-ed ; l'aide « Essayer J-ed » guide la visite).
Le dossier extrait à l'étape 7 ne sert qu'à lancer l'assistant : J-ed est installé dans son propre dossier (par exemple C:\J-ed\jed-X.Y.Z), qui contient aussi l'assistant. Pour les mises à jour, ouvrez l'assistant (raccourci « Assistant J-ed ») et cliquez sur Mettre à jour une installation.

10. Derrière un proxy (réseau d'entreprise ou d'établissement)

Si Windows passe par un proxy, Docker doit aussi y passer :

  1. dans Docker Desktop : Settings (roue dentée) → Resources → Proxies ;
  2. choisissez System proxy pour Docker Desktop et pour les conteneurs (le proxy de Windows est repris, y compris un fichier de configuration automatique « PAC » réglé dans Windows) ;
  3. Apply & restart, puis attendez la baleine immobile.

Dans l'assistant, laissez cochée la case « Mon réseau passe par un proxy : utiliser celui de Windows » (cochée d'avance si un proxy est détecté) : J-ed s'en servira aussi. Le bouton « Docker joint-il Internet ? » vérifie que tout est bien réglé. Un proxy qui demande un identifiant et un mot de passe se règle à la main (l'assistant n'écrit jamais de mot de passe).

11. En cas de problème

Ce que vous voyezQue faire
« Docker Desktop n'est pas démarré » ; « error during connect » Ouvrez Docker Desktop et attendez la baleine immobile, puis recommencez.
« WSL » en rouge ; Docker Desktop parle de WSL au démarrage Refaites l'étape 3 (wsl --update), puis redémarrez l'ordinateur.
« Virtualisation » en rougeVoir l'étape 2.
« Docker ne joint pas Internet » ; « context deadline exceeded » Vérifiez la connexion ; derrière un proxy, voir l'étape 10.
« Le port … est déjà utilisé »Choisissez un autre port dans l'assistant (il en propose un libre).
Le disque est pleinLibérez de la place (voir l'étape 6).
Rien ne s'ouvre en double-cliquant sur J-ed.cmd Débloquez l'archive et extrayez-la de nouveau (étape 7). Sinon, ouvrez un Terminal dans le dossier (clic droit sur le fond du dossier, « Ouvrir dans le Terminal ») et tapez powershell -ExecutionPolicy Bypass -File .\assistant\assistant-j-ed.ps1 : le message affiché dit pourquoi.
Mot de passe de J-ed oubliéAssistant → Opérations de maintenance → Mot de passe oublié.
Autre choseAssistant → Ça ne marche pas : un compte rendu (sans aucun mot de passe) est enregistré sur le Bureau ; envoyez-le à la personne qui vous aide.
